# Граф зависимостей Rust Cargo — вариант 8

Программа собирает граф зависимостей пакета через API реестра Cargo
или из локального CSV. Реализованы рекурсивный BFS с ограничением глубины
и исключением пакетов по подстроке, DFS-подобный вывод дерева с отметками
циклов, поиск прямых обратных зависимостей и генерация SVG.
Для SVG не требуется установка Graphviz.

## Требования и запуск

Python 3.10 или новее. Программа использует стандартную библиотеку.
Команды выполняются из корня проекта:

```sh
bash run.sh examples/config.csv --tree --reverse serde
```

Пример обращается к crates.io и требует доступа к сети.
Параметр `--tree` выводит дерево в терминал, `--reverse PACKAGE` — список
узлов собранного графа, непосредственно зависящих от указанного пакета.
SVG записывается по пути `output`; существующий файл перезаписывается.

## Конфигурация CSV

Каждая строка содержит ключ и значение. Все ключи обязательны.
Пустые строки и строки, начинающиеся с `#`, игнорируются.

| Ключ | Значение |
| --- | --- |
| `package` | Имя начального пакета, непустая строка |
| `repository` | URL реестра или путь к CSV тестового репозитория |
| `test_mode` | `true`, `false`, `yes`, `no`, `1` или `0` |
| `version` | Версия начального пакета; в тестовом режиме не используется |
| `output` | Путь к выходному SVG |
| `max_depth` | Целое неотрицательное число; корень имеет глубину 0 |
| `exclude` | Подстрока исключаемых имён; пустое значение отключает фильтр |

В сетевом режиме для зависимостей выбирается последняя стабильная версия
(или последняя доступная), зависимости `dev` и необязательные пропускаются.
На предельной глубине пакет включается, но его зависимости не запрашиваются.
Относительные пути разрешаются от текущего рабочего каталога.

## Тестовый режим без сети

Создайте `examples/test_config.csv` с содержимым:

```csv
package,A
repository,examples/repository.csv
test_mode,true
version,1
output,/tmp/variant8-test.svg
max_depth,3
exclude,
```

```sh
bash run.sh examples/test_config.csv --tree --reverse D
```

В CSV репозитория первое поле — имя пакета в верхнем регистре,
остальные поля — его зависимости. Пример: `A,B,C`.
В комплекте есть граф с общими зависимостями и циклом.

## Проверки

Для тестов требуется pytest (`python3 -m pip install pytest`).

```sh
python3 -m pytest -q
python3 tools/check_quality.py
```

Проверка качества охватывает Python-файлы в `src`, `tests` и `tools`:
строки до 80 символов, функции до 40 строк (включая пустые строки),
цикломатическая сложность до 10 и отсутствие числовых литералов
непосредственно в сравнениях. Сложность считается по AST с учётом
логических операторов, генераторов и вложенных функций.
